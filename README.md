# DeepSeek Token Dash 🐋

实时监控 DeepSeek API token 消耗的桌面应用，美观、轻量、开箱即用。

## 功能

- ⚡ **实时监控** — token 消耗速度、每次请求明细
- 💰 **费用换算** — 自动计算花费金额
- 📊 **历史统计** — 今日/本周/本月趋势图表
- 🔔 **预算告警** — 设置上限，超限提醒
- 🖥️ **桌面原生** — 系统托盘、悬浮窗、开机自启

## 架构

Tauri + React + Rust 代理

## 快速开始

```bash
# 安装依赖
pnpm install

# 开发模式
pnpm tauri dev

# 构建
pnpm tauri build
```
